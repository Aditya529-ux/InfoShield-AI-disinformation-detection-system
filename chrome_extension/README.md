# InfoShield Chrome Extension (Manifest V3)

This extension connects directly to your local InfoShield backend running on `http://localhost:8000`.

## Features
* **In-Page Text Highlight:** Select any statement on any article or website.
* **Right-Click Context Menu:** Right-click highlighted text and choose **"🛡️ Verify with InfoShield"**.
* **Floating Real-Time Badge:** Shows verdict (Reliable vs. Disinformation), confidence %, and influential keywords.
* **In-Browser Feedback:** Submit corrections (Agree, Disagree) right from Chrome to trigger the active continual learning loop.

## How to Install in Google Chrome:
1. Open Google Chrome.
2. In the URL bar, go to: `chrome://extensions`
3. In the top-right corner, turn on **"Developer mode"**.
4. Click the button that says **"Load unpacked"** (top-left).
5. Browse to and select this folder: `/home/Aruuu/int395/chrome_extension`
6. Pin InfoShield to your extensions toolbar!
