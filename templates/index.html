🧩 Chrome Extension (Manifest V3) Integration

InfoShield connects directly with Google Chrome. Highlight any sentence or paragraph on any website to verify claims against your localhost model!

How to Install into Google Chrome:

  1. Open Google Chrome and navigate to chrome://extensions
  2. Toggle "Developer mode" on in the top-right corner.
  3. Click the "Load unpacked" button.
  4. Select the directory: /home/Aruuu/int395/chrome_extension
  5. Done! InfoShield is now pinned to your Chrome toolbar.

Extension Capabilities:

  • In-Page Selection: Select text anywhere on the web to trigger verification.
  • Right-Click Context Menu: Right-click selected text and select "Verify with InfoShield".
  • FastAPI Bridge: Communicates seamlessly with your local InfoShield backend at http://localhost:8000/api/predict.
  • In-Browser Feedback: Directly submit thumbs up/down corrections from Chrome to update datasets/user_feedback.json.
